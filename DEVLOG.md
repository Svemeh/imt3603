**Plus / minus / delta; 12/10/2026**

- \+ plus, What is going well?

  We have a almost fully functioning core gameloop. We’re only missing the delivery point being pushed which is currently beeing worked on as we speak, and closed to being finished. The core game mechanics in the loop works as they’re supposed to, and the game logic itself is functioning as intended by the designers (aka us). The game models for the items and for the different machines in game are designed and placed into the game world, they are also tested by each member of the group and works as intended for everyone.

- \- minus, What is going badly?

  Some core mechanics needs to be polished, and the last core mechanic (delivery zone) is not in the main branch yet, but its being worked on. The map itself isnt fully designed yet and we only have a kind of test map, when we have tested the game loop the map hasnt been included in the world so map design and general playablility compared to what we set out for isnt tested yet. We have no way as of yet to play round 2, youre only able to play one round and then the game stops, and you have to restart the game.

- Δ delta, What will we change?

  The map will probably be changed since we havent actually tested the playability of it yet with all the functioning models inside. The map is based of a paper sketch which Tobias drew down. Some functionallity in the core mechanics may change if the core gameloop principles are ignored in them or deviated from. Character movement and so forth may be changed to fit the chaos in a round.

**Plus / Minus / Delta; 23/10/2026**
- \+ plus, What is going well?
  We have a playable game from the start of a round to the end of a round, and all the simple functionallity to make this happen is done. The station design is done, and the map layout is done, so the stations are placed on the map and are functional and interactable. We have a clear vision for what needs to be produced, we just need to implement it into the game.
  
- \- What is going badly?
  We are missing the full picture of the game, since you can only play one round its not really a game yet, the player just does stuff and get money it cant even use. We have been a little lazy, we need to work more the coming weeks to actually achieve what we want to achieve, not necasseraly more work but just more structured. We havent kept everyone in the loop, hard for people to start on a new task if they dont know whats going on. The map needs to be more populated.
  
- \ Δ delta, What will we change?
  We need to have more meetings so that everyone knows what they are supposed to do. Need to have better communication on discord and tell each other “im taking this issue” or “starting on bla bla bla”, to keep eachother in the loop and get a more streamlined work process. Ethical hacking and the graphics course are also basically done now, so we’ll have more time for the game just by default. We need to create a feeling, we need people to want to play our game, and like the music/sound effects and so forth, right now we are missing this and its a completely different feeling playing a game with music contra a game without it.
